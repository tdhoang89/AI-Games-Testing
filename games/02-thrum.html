How to play
01Each node pulses at its own tempo. The sweeping arc shows when it fires next.
02Click to release a wave. Any node the wavefront touches restarts its pulse from that instant.
03Two or more nodes firing at the same moment is a chord. Bigger and tighter chords score far more.
04The wave travels. Distant nodes reset later than near ones — aim so the delay lands them together.
05Nodes left in sync stay linked and keep firing on their own, with no further input.
06Every repeat raises that set's sustain. A machine left to run is worth far more than a fresh hit.
07A wave resets the sustain of every node it touches. Growing a machine costs its streak — aim so it doesn't.
08Resonance drains faster and faster. Only chords refill it.
